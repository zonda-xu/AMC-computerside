# 电脑连接助手界面

沿用现有手机端的蓝色、冷白底色与中文界面用语。此界面以完成设置为目标（Operate），不替换手机端视觉系统。

- 字体：系统 UI 字体，Windows 使用 Segoe UI / Microsoft YaHei，macOS 使用 PingFang SC；正文 15px / 1.65，一级标题 32px，窄屏 26px。
- 背景 #F1F4FA，表面 #FFFFFF，正文 #1C2941，次要文字 #596980，分隔线 #CDD7E6。
- 主操作 #3565C5 / #FFFFFF，选中底色 #E4EDFF，成功 #25734F，失败 #B33248。
- 宽屏左侧显示有序五步，右侧呈现当前任务；窄屏步骤缩为顶部导航，表单与配对区单列。
- 表单拥有可见标签、键盘焦点和就地检测结果；二维码以黑白原图展示，不叠加装饰，并在过期或使用后隐藏。
- 每个步骤只有一个主推进操作。运行、配对、程序检测是独立状态；未实测的登录和原生任务明确标记待验证。
- 44px 控件，12px 容器圆角；不加载远程字体、脚本或图片。
