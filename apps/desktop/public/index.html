连接方式

同一网络的三个小检查

  1. 手机与电脑接入同一 Wi-Fi，避开访客网络和设备隔离。
  2. 只在可信的专用网络中，允许网关使用 TCP 8899。
  3. 如果电脑 IP 变化，回来更新地址并重新为手机配对。可在路由器上固定电脑 IP。
还没有配置 EasyTier？生成主机与中转配置
  1. 在电脑和服务器安装与你现有部署一致的 EasyTier（项目基线为 2.6.4）。
  2. 首次部署可留空密钥，生成新网络配置。其他电脑加入同一网络时，填写同一密钥。
  3. 将 host.toml 留在这台电脑；将 relay.toml 放到独立的中转服务目录。已有中转服务时，不要覆盖其配置。
  4. 使用 easytier-core -c host.toml 启动电脑端。
  5. 服务器以 easytier-core -c relay.toml 运行独立实例，开放 TCP 12080 和对应的公网入口；保留端到端 TLS。
  6. 返回此页重新检测网卡，确认指定的 10.89.90.x 地址出现。

配置文件内包含网络密钥。仅交给受信任的部署者，不要发给手机或上传公开仓库。

扫码失败或无法连接？
  • 二维码过期或已经使用：点击重新生成，旧二维码立即失效。
  • 局域网模式：检查同一 Wi-Fi、电脑防火墙和网卡地址。
  • 远程模式：检查域名解析、EasyTier 本机地址及服务器 TCP 映射。
  • 证书失败：检查手机与电脑时间，以及证书域名，不要关闭证书验证。
