AMC 电脑连接助手 v0.2.0 — 适配 2026-11-13 工作区版本 AI Maid Café（协议版本仍为 1）。

本次更新：

- 同步网关、协议、四类适配器和 DSH 桥接实现，支持新版手机的授权根目录查询、幂等项目目录创建和操作状态查询。
- 增加外部会话能力查询、发现、历史只读导入与观察刷新；具体能力受运行时版本和已验证配置限制，不能据此接管现有终端。
- 同步 Codex 会话恢复和原生模型确认逻辑；待选模型保存后发送 catalog.changed，让手机刷新权威状态。
- DSH 0.2.1-rc.5 保持只读，拒绝未验证的控制、接管和模型切换；Claude Code / OpenCode 不虚报外部导入能力。
- 独立源码导出排除手机专用测试，保留网关和适配器的回归测试与合成协议夹具。

升级：先在旧助手中停止网关并退出助手，解压新包到独立目录，按原方式启动。同一系统用户继续复用 ~/.ai-maid-cafe/desktop；不要删除或覆盖其中的身份、证书、设备授权和数据库。自定义配置用户继续使用原配置路径。DSH 桥接需一起升级并按 HOST_SETUP.md 配置。

模型列表不会因升级自动填充。请在本机配置中登记原生程序实际支持的 provider/model 标识，重启网关后在手机刷新；不要把“已安装”当作模型已验证。旧手机的 NO BIND SOCKET 必须更新手机应用才能修复，本次电脑包不包含手机应用。

自动测试不等于用户 Mac、真实 AI 账号、手机和中转服务器的端到端验收。

保留的电脑端功能：

- 本机浏览器五步向导：环境检查、网络选择、AI 程序与项目目录、扫码配对、首次任务。
- 同一 Wi-Fi 直接连接；可生成原独立 EasyTier 网络的主机和中转配置。
- 自动保存完整原生程序版本，生成独立 TLS 身份，管理网关启停。
- 二维码与 JSON 配对，120 秒有效且单次使用；支持大图扫码、入口检测和设备撤销。
- 三个包只包含电脑端必需代码与 JavaScript 依赖，不含 HarmonyOS、人物素材和任何个人配置。

使用方式：下载对应系统的 ZIP → 完整解压 → 打开 START-HERE.html → 运行本系统启动入口。

需要先安装 **Node.js 24.13+（24.x）、OpenSSL，以及自己的 AI 程序**。运行包不需要 npm install。macOS / Linux 可能需要为启动脚本添加执行权限。

Windows 本机已验证向导、真实 TLS 配对、设备撤销和网关重启。自动测试不代表 HarmonyOS 真机、真实 AI 账号会话或用户 VPS 网络已经验收。三个操作系统的自动测试结果见本版本关联的 GitHub Actions 运行。macOS / Linux 图形桌面的启动与真实手机扫码仍需目标机器确认。

分发包 SHA-256 校验值见附带的 SHA256SUMS.txt。包未提供原生系统签名安装程序，也不捆绑 Node.js / OpenSSL。
