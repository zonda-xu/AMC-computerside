# AMC 电脑连接助手 v1.0.0

本版支持在电脑和手机上管理同一个会话目录。可以置顶、重命名、归档和恢复会话。两端同时修改时，网关会检查会话版本，提示刷新后再操作。

- 桌面工作台更新了会话列表，并可配置已配对的 Cage 浏览器，从手机请求在电脑打开公网链接。
- 网关更新了媒体文件读取和会话恢复逻辑，并更新了 Codex、Claude Code、OpenCode 和 DeepSeek Harness 适配器。
- 网关在归档或删除前会检查运行状态、待处理指令和审批，避免中断正在进行的会话。

## 下载与升级

1. 下载与你的系统对应的 Windows、macOS 或 Linux ZIP。可用同一发布页的 `SHA256SUMS.txt` 核对下载文件。
2. 在旧助手中停止网关并退出。将新包完整解压到新目录，保留原来的配置和 `~/.ai-maid-cafe/desktop` 数据目录，以便沿用主机身份、配对记录和会话。
3. 打开包内的 `START-HERE.html`，按说明运行本系统的启动入口。标准包需要本机已安装 Node.js 24.13 或更高的 24.x 版本、OpenSSL，以及所使用的 AI 程序。
